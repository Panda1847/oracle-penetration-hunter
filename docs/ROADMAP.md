# Roadmap

This roadmap reflects current direction and is subject to change based on
community feedback. Want to influence it? Open a
[feature request](../.github/ISSUE_TEMPLATE/feature_request.md) or join the
[Discussions](../../discussions).

## ✅ Shipped (V4.0.0)

- [x] Scope-guarded mission execution
- [x] Evidence-graph findings tracking
- [x] AI-assisted reconnaissance advisory layer
- [x] Core HTML/JSON reporting

## 🚧 In Progress

- [ ] `Adding local LLM support via Ollama, improving the attack graph visualization, and expanding the exploit module set.`
- [ ] Expanded module library for common recon tasks
- [ ] Improved report templates

## 🔭 Planned

- [ ] Local/offline AI model support for air-gapped lab environments
- [ ] Android (ADB-based) target module for mobile app assessments
- [ ] ESP32 / embedded/RF reconnaissance module
- [ ] Plugin marketplace for community-contributed modules
- [ ] Web UI for mission monitoring (CLI remains the primary interface)

## 💡 Under Consideration

- [ ] Team/multi-operator mission collaboration
- [ ] Integration with common ticketing systems for finding hand-off
